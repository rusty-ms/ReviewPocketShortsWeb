## Overview

This is the companion website for the **ReviewPocketShorts** YouTube Shorts channel. It hosts a product page for every video posted, with affiliate links, product details, and an embedded YouTube Short.

**Live site:** https://reviewpocketshorts.com  
**Hosting:** Cloudflare Pages, connected directly to this repo (not GitHub Pages —
`CNAME`/`_config.yml` were leftover Jekyll/GitHub Pages artifacts from an earlier
design and have been removed; Cloudflare's custom-domain config lives in its
dashboard, not in this repo).

---

## How It Works

This repo is **auto-updated by the pipeline** — you never need to push to it manually.

Every time a new video is generated by the ReviewPocketShorts GitHub Actions
pipeline (`.github/workflows/amazon_video_bot.yml` in the `ReviewPocketShorts`
repo):

1. `website_publisher.py` clones this repo fresh
2. Generates a new product page at `/products/{ASIN}.html` (works even before/without
   a YouTube video — falls back to the product's own image)
3. Updates `products.json` (product index + featured product)
4. Regenerates `sitemap.xml`
5. Commits and pushes — Cloudflare Pages deploys automatically within ~30 seconds

## File Structure

```
ReviewPocketShortsWeb/
├── index.html          # Homepage — features latest product, lists all products
├── products.json       # Product index (auto-generated by pipeline)
├── sitemap.xml         # SEO sitemap (auto-generated by pipeline)
├── robots.txt          # Search engine directives
├── ads.txt             # AdSense verification — placeholder until AdSense is approved
├── assets/
│   ├── style.css       # Stylesheet (includes .ad-slot styling)
│   └── main.js         # Homepage JS (loads products.json)
└── products/
    ├── example.html    # Template — {{PLACEHOLDER}} vars filled in by website_publisher.py
    └── {ASIN}.html     # One page per product (auto-generated)
```

## Monetization

Two independent revenue streams, both already wired into every page:

1. **Amazon affiliate links** — every product/CTA link carries `?tag=reviewpockets-20`. Live.
2. **Google AdSense** — ad slots (`.adsbygoogle.ad-slot`) are placed on the homepage
   (2 slots) and every product page (1 slot), loading the real AdSense script. They
   currently show nothing because `ca-pub-XXXXXXXXXXXXXXXX` is a placeholder — apply
   for AdSense on this domain, then once approved:
   - Replace every `ca-pub-XXXXXXXXXXXXXXXX` in `index.html`, `products/example.html`,
     and all existing `products/*.html` with your real publisher ID
   - Uncomment the real line in `ads.txt` with that same ID
   - New pages generated by `website_publisher.py` will need the same replacement
     applied to `products/example.html` (the template) so future pages pick it up
     automatically — existing pages were patched directly and won't regenerate on
     their own.

## Manual Operations

### Trigger a publish manually (from a local checkout of ReviewPocketShorts)
```bash
cd ReviewPocketShorts
python -c "
from scripts.website_publisher import publish_to_website
# publish_to_website(product, youtube_result) — fill in product/youtube dicts
"
```

### Check deployment status
Cloudflare Pages deploys within ~30 seconds of a push. Check:
- Cloudflare dashboard → Pages → this project → Deployments
- Or just visit the live URL
